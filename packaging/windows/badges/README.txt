Папка для ТВОЇХ кастомних бейджів (картинок до ніків).

Поклади сюди PNG/SVG і підключи у chat.ron, секція  badges.
Шлях береться ВІДНОСНО цієї папки-бандла, тому пиши, наприклад:

    badges: Some((
        definitions: {
            "vip_custom": ( uri: "file://badges/vip.png", priority: 1, height: 1 ),
        },
        per_role: {
            "vip": (badges: ["vip_custom"], hide_native: true),
        },
    )),

Готові приклади — у ГАЙД.txt, розділ 8 «КАСТОМНІ БЕЙДЖІ».

Підказки:
  * priority обов'язкове і має бути > 0 (менше = лівіше в рядку бейджів).
  * height у em (1 = як нативний бейдж Twitch).
  * можна й посилання з інтернету: uri: "https://…/badge.png".
  * файл, якого немає, дає WARN у лозі й порожнє місце — не став
    hide_native: true, поки картинки немає.

Цей файл можна видалити.
